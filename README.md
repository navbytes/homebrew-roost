# homebrew-roost

**Moved.** The roost formula now lives in the general
[`navbytes/homebrew-tap`](https://github.com/navbytes/homebrew-tap):

```sh
brew install navbytes/tap/roost
```

Already installed from here? `tap_migrations.json` redirects you — on your next
`brew update` + `brew upgrade`, brew switches the formula to the new tap
automatically. Then drop this tap:

```sh
brew untap navbytes/roost
```

This repo stays up only for that redirect. Issues and pull requests belong in
[navbytes/roost](https://github.com/navbytes/roost).
